# Mapa de documentação

Cada assunto possui uma fonte de verdade:

- objetivos, público, escopo e hipóteses comerciais: [PRODUCT.md](../PRODUCT.md);
- linguagem do domínio: [CONTEXT.md](../CONTEXT.md);
- direção visual e de interação: [DESIGN.md](../DESIGN.md);
- fluxo de trabalho e guardrails para agentes: [AGENTS.md](../AGENTS.md);
- estrutura do sistema: [architecture/](architecture/);
- decisões técnicas difíceis de reverter e seus motivos: [adr/](adr/);
- invariantes de domínio: [business-rules/](business-rules/);
- procedimentos operacionais repetíveis: [runbooks/](runbooks/).

[doc/doc-inicial.md](../doc/doc-inicial.md) é o material original de produto e arquitetura; [doc/plano-inicial.md](../doc/plano-inicial.md) é a autoridade para sequência de implementação e critérios dos gates. Para conteúdo de produto, termos, design, arquitetura e invariantes, use os arquivos canônicos acima. Quando essas fontes exigirem uma mudança, atualize o plano no mesmo pull request.
